+128. **Compose ViewModel Injections Must Be Scoped with `remember` / `currentKoinScope`**: When resolving ViewModels declared as `factory` in Koin within Composable functions, the injection MUST be scoped using `remember { currentKoinScope().get<ViewModel>() }` (or `remember(key) { currentKoinScope().get { parametersOf(key) } }`). Calling `koinInject()` directly inside a Composable body causes a new ViewModel instance to be created on every recomposition, triggering `DisposableEffect(viewModel)` to dispose and cancel active coroutines/scopes repeatedly and creating an infinite recomposition loop that starves input dispatch and freezes loading states.
+129. **Surface Borders Must Use `border = BorderStroke(...)` Parameter**: Clickable Material3 `Surface(onClick = ...)` composables MUST specify borders via the `border = BorderStroke(...)` constructor parameter rather than `Modifier.border(...)`. Applying `Modifier.border` to a `Surface` causes the border to wrap the outer interactive minimum touch target bounding box (48dp x 48dp) rather than the measured intrinsic shape of the surface, creating visible ghost border boxes around buttons.
